# Projeto e Análise de Algoritmos (PAA)

Este repositório reúne os materiais, exercícios e conteúdos desenvolvidos durante a disciplina de **Projeto e Análise de Algoritmos (PAA)**.

## Sobre a disciplina

A disciplina de Projeto e Análise de Algoritmos tem como objetivo desenvolver a capacidade de analisar problemas computacionais, avaliar a eficiência de algoritmos e projetar soluções utilizando diferentes estratégias de desenvolvimento.

De forma geral, a disciplina é dividida em **três grandes áreas**:

### 1. Análise
Foca na avaliação do **custo computacional** dos algoritmos, considerando principalmente:
- Complexidade de tempo;
- Complexidade de espaço;
- Ordens de crescimento (notação assintótica);
- Comparação entre diferentes soluções para um mesmo problema.

### 2. Tratamento
Estuda como **atacar problemas computacionalmente difíceis**, analisando sua tratabilidade e identificando estratégias que permitam obter soluções eficientes ou aproximadas quando uma solução exata não é viável.

### 3. Projeto
Consiste na **implementação de soluções** utilizando diferentes paradigmas e técnicas de projeto de algoritmos, escolhendo a estratégia mais adequada para cada tipo de problema.

## Conteúdo estudado

Ao longo do semestre foram abordados os seguintes tópicos:

- Visão geral da disciplina e conceitos fundamentais;
- Revisão de Grafos;

- Tratabilidade;
